# 8-Ball Pool

A recreation of the GamePigeon "8-Ball" iMessage game. Single self-contained
HTML file, no dependencies. Open `index.html` in any browser.

## Rules
- Two players, hot-seat on one device.
- Table starts open. The first player to legally pot a solid or stripe takes
  that group; the opponent gets the other.
- Pot all your group, then pot the 8-ball to win.
- Fouls (scratch, hitting the wrong ball first, or no contact) give the
  opponent ball-in-hand.
- Potting the 8-ball early, or on a scratch, loses the game.

## Controls
- Drag from the cue ball, pull back to set power, release to shoot.
- Aiming line shows the projected contact point (ghost ball).
- On ball-in-hand, tap an open spot to place the cue ball.
- **New Game** re-racks.
